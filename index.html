PROJECT 01

FINTECH PRO - EXPENSE & INCOME TRACKER

OBJECTIVE

To build a simple and user-friendly personal finance tracker that helps users record their income and expenses, monitor their balance, and understand their spending habits.

PROBLEM

Users often need a quick and simple way to keep track of daily income and expenses without relying on complex financial applications. The project addresses this by providing an easy-to-use interface for managing basic financial transactions.

ROLE

Frontend Developer - responsible for UI design, HTML structure, CSS styling, JavaScript functionality, transaction handling, balance calculations, and overall project implementation.

PLANNING

Defined the core requirements including income and expense entry, transaction display, total income, total expenses, and remaining balance. Focused on a clean responsive layout and a simple user flow suitable for a small-scale finance application.

COORDINATION

Managed the project independently, coordinating the UI structure, styling, and JavaScript functionality while ensuring that all components worked together consistently.

TECHNICAL CONTEXT

Built using HTML5 for structure, CSS3 for responsive styling and visual design, and vanilla JavaScript for transaction management, income and expense calculations, dynamic DOM updates, and user interactions.

EXECUTION

Designed the interface first and then implemented the transaction logic using JavaScript. Added functionality to record income and expenses, dynamically update transaction lists, calculate totals, and display the current financial balance. Tested the interface and interactions across different screen sizes.

OUTCOME

Delivered a functional and responsive expense and income tracker that allows users to manage basic transactions and view their overall financial status through a clear and intuitive dashboard.
